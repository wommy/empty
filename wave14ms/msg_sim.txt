zfstest: model rename and guid; fuzz no longer nests below a zvol

The simulator gains `zfs rename` (descendants, snapshots, holds and the
clone/origin graph move; shares follow the new mountpoint) and a guid
per dataset that survives the rename, so an observer can tell a renamed
dataset from a new one. Both live in sim_ext.go; sim.go only gains the
hooks.

FuzzReconcileSafe made a child dataset below a clone of a zvol, which
zfs refuses ("parent is not a filesystem", which the simulator now
models); it now tracks zvol clones (seed 9abef424 kept).
