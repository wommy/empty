The start step now tries the GitHub release first, now with time bounds, verifying
it against BUF_SHA256 (39716cfe0185df3cba21f66ec739620ffb6876c48b2da4338a8c68c290c9b116).
If the download or the check fails, it downloads the same release from the
official @bufbuild/buf-linux-x64 1.47.2 npm package on registry.npmjs.org
and verifies that against BUF_FALLBACK_SHA256
(cba025de34f5fe8125cf32b03762a09488495fee341ac4af2a23f9d2ed8ce3b8).

step installs it. Each curl is capped by an outer timeout 45 as well as
--max-time, and the background step writes buf.status (ok or fail) and
buf.log, which the install step prints. The install wait is 100s
(200 x 0.5s), up from 60s.
